# 🧮 Python Simple Calculator

## Project Description

This project is a  Simple Calculator Program in Python that performs basic arithmetic operations.
The program allows the user to select an operation and enter two numbers to calculate the result.

##  Features

* Addition
* Subtraction
* Multiplication
* Divide
## Example Output

Please select an operation:
1. Addition
2. Subtraction
3. Multiplication
4. Divide

Enter choice: 1
Enter first number: 10
Enter second number: 5

Result: 15
